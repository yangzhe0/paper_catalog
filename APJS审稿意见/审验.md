你现在的任务是做一次**独立返修审计**，不是继续修改论文，也不是根据已有总结直接确认结果。请先不要改任何文件，先完整审查并输出审计报告。你的目标是判断本轮 ApJS 返修是否真正、合理、完整地回应了审稿人和 Data Editor 的意见。

## 审验原则

1. 不要相信已有 response letter 或之前的总结。
2. 必须从原始审稿意见、当前稿件、git diff、图片源码、生成图片和 response letter 中独立核验。
3. 先只审计，不要擅自修改文件。
4. 每个结论都要给出证据：文件路径、行号、关键词或 diff 依据。
5. 重点找遗漏、过度修改、术语风险、图文不一致、response letter 夸大或不准确的问题。
6. 请区分四类结论：
   - 已完成；
   - 基本完成但建议优化；
   - 未完成；
   - 有风险但可接受。
